# Team Planner — Responsive VS Code Project

## Run
1. Install Node.js 18+.
2. Open this folder in VS Code.
3. Terminal:
   npm install
   npm run dev
4. Open the Vite URL shown in terminal.

For iPad testing on the same Wi-Fi, run:
   npm run dev -- --host 0.0.0.0
Then open `http://YOUR-COMPUTER-IP:5173` on the iPad.

## Demo accounts
Login page lets you choose:
- System Admin
- กิตติ รุ่งเรือง (Manager)
- สมชาย ใจดี (Employee)

This is a front-end simulation. Data resets when the page is refreshed.
